Week 7: JS Best Practices

This week I learned how to write code that actually lasts — persistent data, clean structure, and code a teammate could actually read.

🇰🇪 Nairobi Market 📚 School Tasks

What I Built This Week

💾

localStorage

Learned to persist data across page refreshes using localStorage. Objects need to be serialized with JSON.stringify first — you can't just store them directly.

🛒

Nairobi Street Market

Built a full shopping cart for Kenyan street food — mandazi, chapati, nyama choma and more. Cart persists across refreshes. Add items, adjust quantity, place your order.

📚

Persistent To-Do List

Upgraded the Week 5 school task manager so tasks survive page refreshes. Added centralized state management, created-date display, and an export to clipboard feature.

🧠

State Management

Centralized all app state into one object. Every change goes through setState() which saves to localStorage and re-renders. Much cleaner than scattered variables.

✨

Clean Code

No more magic numbers. Named constants, single-responsibility functions, meaningful variable names. The refactor challenge showed me how messy my early code actually was.

🔍

Self Code Review

Reviewed the Week 6 weather dashboard against a proper checklist. Found 3 real bugs and 4 improvements. Gave it 7/10 — honest but fair.
